# 📘 五笔学堂 (Wubi Master) 产品设计与功能规范文档

> 最后更新：2026-09-17 v1.7.3

## 一、产品定位与核心目标

**五笔学堂**是一款专为中文打字进阶者、办公专业人员、速记录入员及汉字文化爱好者打造的**现代化、跨版本、全功能五笔字型研习平台**。

### 核心痛点与解决思路

1. **传统打字练习软件老旧、广告繁多**→ 采用现代响应式暗色高质感设计，纯净无广告，极简聚焦
2. **多版本五笔互不通晓**→ 全面打通 86 版（普及度最广）、98 版（规范性强）和新世纪版（字根更科学），同屏对比学习
3. **字根拆分盲目、误认识别码**→ 市面许多练习软件机械按字母拼字根，甚至将末笔交叉识别码当成字根展示。本系统严格分离"构字字根"与"识别码"，真实还原汉字构形
4. **长文练习篇幅碎片化**
   → 提供传世名篇"无删减全文"，配套专业阅读视口、自动跟滚动与多模式导入，让练习真正具备实战耐力价值

### 1. 打字特训模块 (`TypeEngine.vue`)

#### 1.1 循序渐进的梯度体系

| 练习类型             | 字符数  | 适用人群 | 训练目标                   |
| -------------------- | ------- | -------- | -------------------------- |
| **一级简码**   | 25字    | 入门必学 | 高频字一键出字，速度质变   |
| **键名字**     | 25字    | 基础练习 | 熟悉键位分布，掌握四码重复 |
| **常用字500**  | 500字   | 日常基础 | 覆盖日常80%使用场景        |
| **常用字1500** | 1,500字 | 流畅进阶 | 达到盲打流畅水平           |
| **常用字3500** | 3,500字 | 全量精通 | 国标规范常用字全覆盖       |
| **双字词组**   | 动态    | 进阶强化 | 前二+次二连续击键节奏      |
| **四字成语**   | 动态    | 高级技巧 | 四字各取首码，速记训练     |

#### 1.2 书法风米字格 (MiZiGe)

**设计理念**：传统书法美学 + 现代交互设计

- **主格展示**：优雅的大号传统米字格展示目标字，上方标注汉语拼音
- **字根拆解**：每个字根以迷你米字格陈列，清楚标识"第N码 / X键"
- **识别码独立标记**：虚线徽章独立陈列（如 `末笔识别: K键·杂合型`），避免混淆

**示例**：

```
目标字：晋 (jìn)
┌─────────────────────────────┐
│  字根拆解                    │
│  [一] 第1码/G键              │
│  [业] 第2码/O键 (业字头)     │
│  [一] 第3码/G键              │
│  [日] 第4码/J键              │
│  识别码：无（4字根满码）      │
└─────────────────────────────┘
```

#### 1.3 智能简码提示气泡

当用户在全码模式下打某字时，若该字具备简码：

```
💡 发现此字有简码 [RU]，输入速度可提升 50%！
```

#### 1.4 实时打字统计

| 指标             | 说明       | 计算方式                  |
| ---------------- | ---------- | ------------------------- |
| **WPM**    | 每分钟字数 | 正确字数 / 用时分钟数     |
| **KPM**    | 每分钟击键 | 总击键数 / 用时分钟数     |
| **准确率** | 正确率     | 正确字数 / 总字数 × 100% |
| **退格数** | 纠错次数   | 累计按退格键次数          |
| **用时**   | 练习时长   | 从首次击键到完成的秒数    |

#### 1.5 练习控制条 (`TypeEngineToolbar.vue`) 与分批阶段结算 (`TypeResultModal.vue`)

- **双层练习控制条 (`TypeEngineToolbar.vue`)**：
  - **上层功能区**：练习类型分级切换（一级简码 / 键名字 / 常用字 500 / 常用字 1500 / 常用字 3500 / 双字词 / 四字词）；
  - **下层选项区**：
    - **批次规模调节**：提供 25 字 / 50 字 / 100 字 / 全量无限制 四档选择，满足碎片化或耐力训练需要；
    - **辅助开关矩阵**：键位音效、编码提示、字根拆解提示、简码发现提示独立开关；
    - **操作按钮**：一键重置当前练习进度。
- **分批练习结算战报 (`TypeResultModal.vue`)**：
  - 每完成一个批次（如打满 25 字），即时弹出高质感毛玻璃结算弹窗；
  - 汇总展示本批次用时、平均速度 (WPM)、击键速率 (KPM)、整体准确率及退格次数；
  - **错题收录提示**：明确提示本批次录入的生疏错字并已自动同步至错题本；
  - **平滑流转**：支持「🔄 重新挑战本组」或「➡️ 开启下一组」，保持心流节奏。

#### 5.2 微观拆字原则实验室与正误对决 PK (`RuleSplitPrinciples.vue`)

为将抽象的五笔构形理论具象化，系统内置了高度交互的微观拆字实验室：
- **四大基本拆字原则深度剖析**：
  1. **取大优先**：再添一笔不能构成字根时切分（如「丰」拆为「三 + 丨」而非「二 + 十」）；
  2. **兼顾直观**：照顾汉字传统笔顺与直观习惯（如「自」拆为「丿 + 目」）；
  3. **能连不交**：能看成连笔结构的绝不看作交叉（如「天」拆为「一 + 大」而非「二 + 人」）；
  4. **能散不连**：字根之间有间隙时优先视作散体（如「产」拆为「立 + 𠂉」）。
- **正误方案对决 PK**：同屏展示正确拆法 vs 典型错误拆法，标明错误成因与扣分要害；
- **动态微观测试台**：支持学员交互式自选部件并由规则引擎即时校验，强化拆字肌肉记忆。

#### 5.3 识别码推导工具

### 8. 五笔修仙打怪闯关 RPG (`RpgAdventure.vue`)

#### 8.1 玩法定位与设计理念
将五笔输入法击键练习与东方修真玄幻沉浸式 RPG 玩法结合，彻底解决传统打字练习枯燥单调、容易疲劳的痛点。
- **修仙十三阶**：从「第1关：练气初悟」至「第13关：天道渡劫」，贯穿凡界、灵界与仙界。
- **400+ 字符扩容题库**：各关收录代表性高频字、字根代表字、多级简码（一/二/三级简码）及战斗修仙词组，拒绝机械重复。
- **即时战斗（ATB）反馈**：将击键速度与准确度转化为玩家攻击力与连击伤害，怪物具备独立充能计时与狂暴反击机制。

#### 8.2 核心战斗机制与时序

```
┌─────────────────────────────────────────────────────────────┐
│ 玩家 (修仙者)                    VS                 关卡首领 │
│ HP: ██████████ 100/100                 HP: ████████░░ 780/1000│
│ 能量: [⚡⚡⚡⚡⚡] 100% (Tab 释放大招)  ATB: [━━━━━━>   ] 狂暴加成│
└─────────────────────────────────────────────────────────────┘
                              │
               ┌──────────────┴──────────────┐
               ▼                             ▼
       正确击键 / 命中简码             错误击键 / 超时受击
       - 飞剑普攻 (-Hp)              - 玩家扣血 (-5 ~ -15)
       - 连击计数 (Combo +1)         - 连击中断 (Combo = 0)
       - 充能飞剑灵气 (+10%)         - 屏幕受击红光震颤
```

1. **普攻与连击**：每次击中字根/汉字，立即向 Boss 释放飞剑攻击，基础伤害为 `30 + Combo * 2`；
2. **飞剑灵气与「万剑归宗」大招**：
   - 击键正确累积灵气条（满额 100%）；
   - 按下 `Tab` 键或点击技能按钮触发「万剑归宗」：生成 20+ 把全屏剑影粒子爆发，瞬间扣减 Boss 最大生命值 40%，并冰冻 Boss 5 秒阻断其 ATB 充能；
3. **Boss 狂暴机制**：
   - 当 Boss HP <= 35% 时，触发「🔥 残血狂暴」状态，ATB 攻击读条速度提升 30%，带来极限压迫感；
4. **四端统一 0 延迟秒出与 IME 状态机 (`useRpgInput.ts`)**：
   - 彻底废除定时器竞态，击键满 4 码命中合法编码瞬间判定出字，不匹配则瞬间触发走火入魔扣血；
   - 一级简码关卡或 auto 模式即敲即出；
   - IME 组字流拦截，输入法空格选词后立即重置原生输入框，阻断空格向下穿透。

## 三、五笔编码与取码业务规则

### 1. 单字编码取码规则

| 字根数         | 取码规则                       | 示例       | 说明                          |
| -------------- | ------------------------------ | ---------- | ----------------------------- |
| **1个**  | 重复该字根键位4次              | 一 → GGLL | 键名字特殊规则                |
| **2个**  | 字根1 + 字根2 + 识别码         | 中 → KHK  | 口+丨+识别码K                 |
| **3个**  | 字根1 + 字根2 + 字根3 + 识别码 | 业 → OGD  | 业头+一+识别码D               |
| **4个**  | 字根1 + 字根2 + 字根3 + 字根4  | 拼 → RUAH | 扌+丷+一+八                   |
| **5个+** | 字根1 + 字根2 + 字根3 + 末字根 | 缩 → XPWI | 纟+⺌+宀+冖+糸 → 纟+⺌+宀+糸 |

### 2. 末笔字型交叉识别码矩阵表

| 末笔分类            | 左右型 (1) | 上下型 (2) | 杂合型 (3) |
| ------------------- | ---------- | ---------- | ---------- |
| **横 (一区)** | G (11)     | F (12)     | D (13)     |
| **竖 (二区)** | H (21)     | J (22)     | K (23)     |
| **撇 (三区)** | T (31)     | R (32)     | E (33)     |
| **捺 (四区)** | Y (41)     | U (42)     | I (43)     |
| **折 (五区)** | N (51)     | B (52)     | V (53)     |

**字型判定标准**：

- **左右型**：左右结构（如"明"、"林"）
- **上下型**：上下结构（如"茶"、"花"）
- **杂合型**：其他结构（包围型、独体字等）

### 3. 词组整词取码规则

| 词长           | 取码规则   | 公式                               | 示例                            |
| -------------- | ---------- | ---------------------------------- | ------------------------------- |
| **2字**  | 前二+次二  | char[0]前2 + char[1]前2            | 五笔 → GG + TT = GGTT           |
| **3字**  | 首+首+前二 | char[0]首 + char[1]首 + char[2]前2 | 计算机 → 计(Y) + 算(T) + 机(SM) = YTSM |
| **4字**  | 各取首码   | char[0..3]各首码                   | 春暖花开 → D + J + A + G = DJAG |
| **5字+** | 首三+末首  | char[0..2]首 + char[末]首          | 中华人民共和国 → K + W + W + L = KWWL |

## 六、用户体验设计原则

### 1. 渐进式学习曲线

```
入门 → 一级简码(25字) + 键名字(25字)
  ↓
基础 → 常用字500 + 双字词组
  ↓
进阶 → 常用字1500 + 长文篇章
  ↓
精通 → 常用字3500 + 游戏挑战
```

### 2. 即时反馈机制

- ✅ **正确**：绿色高亮 + 清脆音效 + 字符跳转
- ❌ **错误**：红色抖动 + 提示音 + 编码回显
- 💡 **提示**：简码气泡 + 字根展示 + 键盘高亮

### 3. 无障碍设计

- 支持键盘全操作（无需鼠标）
- 字体大小可调节
- 高对比度主题
- 屏幕阅读器友好
